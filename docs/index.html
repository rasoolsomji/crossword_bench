Reading these numbers

  • Accuracy and its interval. Accuracy is exact for the clues asked: correct divided by total. What it estimates is the model's long-run hit rate on cryptic clues in general, and a hundred or so clues only pin that down roughly, the same way a fair coin flipped 116 times rarely lands on exactly 58 heads. The 95% interval is the range of long-run rates that fit the result: a model whose true rate lay outside it would produce a score like this less than one time in twenty. It shrinks as clues accumulate, from about ±9 points at 116 clues to ±4 at 500 and ±2 at 2,000. Until then, two runs with overlapping intervals are not clearly separated; head to head is the sharper test, because both runs faced identical clues.
  • Effort is each provider's own reasoning setting. The labels are not comparable between providers: "medium" on one can spend more reasoning than "high" on another.
  • Harness-backed runs. Models listed without an API (currently the OpenAI models, reached through the Codex app server) run inside an agent harness that adds its own context. Web search was disabled and any attempt to use a tool is cut off and scored as a miss, but treat those rows as indicative.
  • Estimated cost prices each run's tokens at API list prices (pricing.json). It is not what was paid: harness-backed runs went through a subscription, and their input counts include the harness's own prompt.
  • Transcripts include whatever reasoning summary the provider returns. Raw chains of thought are not exposed by either provider, and some models return only a line or two.
  • Device labels are assigned by a classifier model after the runs, from published human parsings. They are not human-verified.
