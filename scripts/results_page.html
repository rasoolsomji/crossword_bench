Cryptic Crossword Bench

How well language models solve cryptic crossword clues they cannot have seen in training. Each clue is posed on its own: no grid, no crossing letters, no tools, no web search. An answer counts only if it matches the published solution exactly.

Reading these numbers

  • Accuracy is simply clues correct divided by clues asked. The interval beside it answers a different question: these clues are a small sample of all the clues a model could be given, so the same model would score a little differently on another week's puzzles. With around a hundred clues that wobble is roughly ±9 points, which is why two models a few points apart are not meaningfully separated. Head to head is the sharper comparison, because both runs faced identical clues.
  • Effort is each provider's own reasoning setting. The labels are not comparable between providers: "default" on one can spend more reasoning than "high" on another.
  • Harness-backed runs. Models listed without an API (currently the OpenAI models, reached through the Codex app server) run inside an agent harness that adds its own context. Web search was disabled and any attempt to use a tool is cut off and scored as a miss, but treat those rows as indicative.
  • Transcripts include whatever reasoning summary the provider returns. Raw chains of thought are not exposed by either provider, and some models return only a line or two.
  • Device labels are assigned by a classifier model after the runs, from published human parsings. They are not human-verified.
